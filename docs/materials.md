# 资料口径

时段起点包含终点不包含。空间相交不自动等同，共享关系由文字明确。出件身份不表示文中每个陈述都是有效许可。执行事实与计划分开。

`data/case.json` 使用 UTF-8，`case_id` 是一次业务资料包编号；`records` 保存原始文本，`id` 稳定，`kind` 说明资料种类，`text` 保留原文。来源的陈述可未核实、互相冲突或被后续文字更正，编号顺序不是业务效力优先级。

`objects` 是对象、关系或场地的业务登记；其中 `source` 和 `sources` 引用原文编号。`existing` 是已经存在的办理记录，`state` 记录当时所处阶段；历史文字可能与后补事实不符，不表示当前仍可采用。接收后补资料时，应保留其原文和独立编号，使用者的解释确认也要能对应具体原句版本。不能因来源有引用便把转述当独立观察。

相同格式可容纳新的对象和原文，不用记录编号表示固定结论。资料中出现的姓名、地点、金额、规则和专业术语均为合成演练内容，不对应真实业务资质。
